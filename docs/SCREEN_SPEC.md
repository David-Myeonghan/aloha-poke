# 화면 설계서 (와이어프레임)

> 이 문서는 Aloha Poke 앱의 화면 레이아웃과 UI 상세 명세를 정의합니다.

---

## 1. 전체 레이아웃 구조

### 1.1 기본 구조

```
┌─────────────────────────────────────────────────────────────┐
│                         HEADER                              │
│  ┌──────────┐  ┌─────────────────────┐  ┌────────────────┐ │
│  │   Logo   │  │    Recent View      │  │   Search Box   │ │
│  └──────────┘  └─────────────────────┘  └────────────────┘ │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│                      MAIN CONTENT                           │
│                                                             │
│                   (Outlet - 페이지별 콘텐츠)                 │
│                                                             │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

### 1.2 레이아웃 수치

| 영역         | 속성       | 값                 |
| ------------ | ---------- | ------------------ |
| Header       | 높이       | 64px               |
| Header       | 배경색     | #1f2949            |
| Header       | padding    | 0 24px             |
| Main Content | padding    | 24px               |
| Main Content | 배경색     | #5b92d3            |
| Main Content | min-height | calc(100vh - 64px) |

## 7. 인터랙션 명세

### 7.1 상태별 UI 변화

#### 포켓몬 카드

| 상태             | 변화                       |
| ---------------- | -------------------------- |
| Default          | 기본 스타일                |
| Hover            | 위로 4px 이동, 그림자 증가 |

| Loading (이미지) | 스피너 표시                |

#### 버튼

| 상태     | 변화                              |
| -------- | --------------------------------- |
| Default  | 기본 색상                         |
| Hover    | 밝기 10% 증가                     |
| Active   | 밝기 10% 감소                     |
| Disabled | opacity: 0.5, cursor: not-allowed |

#### 링크 (최근 본 포켓몬)

| 상태    | 변화                  |
| ------- | --------------------- |
| Default | 흰색 텍스트           |
| Hover   | 밑줄, cursor: pointer |

### 7.2 트랜지션

| 요소        | 속성       | 값                          |
| ----------- | ---------- | --------------------------- |
| 카드 호버   | transition | all 0.2s ease               |
| 버튼        | transition | background-color 0.15s ease |
| 이미지 표시 | transition | opacity 0.3s ease           |
| 스탯 바     | transition | width 0.5s ease-out         |

### 7.3 페이지 전환

## 8. 반응형 브레이크포인트

### 8.1 정의

| 이름       | 범위          | 용도                       |
| ---------- | ------------- | -------------------------- |
| mobile     | ~479px        | 스마트폰 세로              |
| tablet-sm  | 480px~767px   | 스마트폰 가로, 태블릿 작은 |
| tablet     | 768px~1023px  | 태블릿                     |
| desktop    | 1024px~1279px | 소형 데스크톱              |
| desktop-lg | 1280px~       | 대형 데스크톱              |

### 8.2 SCSS 믹스인

```scss
// 사용 예시
$breakpoints: (
  "mobile": 479px,
  "tablet-sm": 767px,
  "tablet": 1023px,
  "desktop": 1279px,
);

@mixin respond-to($breakpoint) {
  @media (max-width: map-get($breakpoints, $breakpoint)) {
```
