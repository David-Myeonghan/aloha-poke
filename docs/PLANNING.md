# Aloha Poke - 서비스 기획서

> **작성일:** 2025년 12월
> **버전:** v0.1.0
> **프로젝트명:** Aloha Poke (포켓몬 도감 웹 앱)

---

## 1. 서비스 개요

### 1.1 서비스 소개

**Aloha Poke**는 포켓몬 정보를 쉽고 빠르게 조회할 수 있는 웹 기반 포켓몬 도감 서비스입니다. 사용자는 다양한 포켓몬의 기본 정보, 능력치, 이미지를 확인할 수 있으며, 최근 본 포켓몬을 자동으로 저장하여 오프라인에서도 빠르게 접근할 수 있습니다.

### 1.2 서비스 목적

- 포켓몬 팬들을 위한 직관적이고 빠른 도감 서비스 제공
- 최근 본 포켓몬 기록을 통한 개인화된 사용자 경험 제공
- 모바일/데스크톱 환경에서 원활하게 동작하는 반응형 웹 서비스 구현

### 1.3 타겟 사용자

| 구분          | 설명                            |
| ------------- | ------------------------------- |
| **주 사용자** | 포켓몬 게임/애니메이션 팬       |
| **연령대**    | 10대 ~ 30대                     |
| **사용 환경** | 모바일 웹, 데스크톱 웹 브라우저 |

| 포켓몬 상세 정보 | 선택한 포켓몬의 상세 정보 조회  | ✅ 완료 |

| 무한 스크롤      | 스크롤 시 추가 포켓몬 로딩      | 🔜 예정 |

### 2.2 기능 상세

#### 2.2.1 포켓몬 목록 조회

**기능 설명:**
메인 화면에서 포켓몬 목록을 카드 형태의 그리드 레이아웃으로 표시합니다.

**세부 사항:**

- 초기 로딩 시 20개의 포켓몬 표시
- 각 카드에는 포켓몬 이미지와 이름 표시
- 카드 클릭 시 해당 포켓몬 상세 페이지로 이동
- 로딩 중에는 로딩 스피너 표시

**사용자 스토리:**

> "사용자로서, 메인 화면에서 포켓몬 목록을 한눈에 보고 싶은 포켓몬을 빠르게 찾고 싶다."

---

#### 2.2.2 포켓몬 상세 정보

**기능 설명:**
선택한 포켓몬의 상세 정보를 확인할 수 있는 페이지입니다.

**표시 정보:**

| 항목   | 내용             | 예시                  |
| ------ | ---------------- | --------------------- |
| 이름   | 포켓몬 이름      | Bulbasaur             |
| ID     | 도감 번호        | #001                  |
| 신장   | 키 (10cm 단위)   | 0.7m                  |
| 체중   | 무게 (100g 단위) | 6.9kg                 |
| 타입   | 포켓몬 속성      | Grass, Poison         |
| 능력치 | 6가지 기본 스탯  | HP: 45, Attack: 49 등 |

**능력치 (Stats) 구성:**

- HP (체력)
- Attack (공격력)
- Defense (방어력)
- Special Attack (특수 공격력)
- Special Defense (특수 방어력)
- Speed (스피드)

**이미지 유형:**

1. **기본 이미지** - 도트 스타일의 기본 스프라이트
2. **꿈 세계 이미지** - Dream World 스타일 일러스트
3. **공식 아트워크** - 고해상도 공식 일러스트

**사용자 스토리:**

> "사용자로서, 특정 포켓몬의 능력치와 타입을 확인하여 게임 전략을 세우고 싶다."

---

#### 2.2.3 최근 본 포켓몬

**기능 설명:**
사용자가 상세 페이지에서 조회한 포켓몬을 자동으로 기록하고, 헤더 영역에서 빠르게 접근할 수 있도록 합니다.

**동작 방식:**

1. 사용자가 포켓몬 상세 페이지 접속
2. 해당 포켓몬이 "최근 본 목록"에 자동 저장
3. 헤더에서 최근 본 포켓몬이 2초 간격으로 자동 회전 표시
4. 포켓몬 이름 클릭 시 해당 상세 페이지로 바로 이동

**특징:**

- 브라우저 IndexedDB에 저장되어 브라우저 종료 후에도 유지
- 동일 포켓몬 재방문 시 중복 저장되지 않고 업데이트
- 인터넷 연결 없이도 최근 본 기록 확인 가능

**사용자 스토리:**

> "사용자로서, 최근에 본 포켓몬을 빠르게 다시 찾아보고 싶다."

## 4. 사용자 플로우

### 4.1 기본 사용 흐름

```
┌──────────────┐    카드 클릭    ┌──────────────┐
│              │ ─────────────→ │              │
│  메인 리스트  │                │   상세 페이지  │
│              │ ←───────────── │              │
└──────────────┘   뒤로가기      └──────────────┘
       ↑                               │
       │                               │
       │         자동 저장              ↓
       │         ┌──────────────────────┐
       │         │  최근 본 포켓몬 저장   │
       │         │  (IndexedDB)         │
       │         └──────────────────────┘
       │                               │
       │         헤더에서 클릭          │
       └───────────────────────────────┘
```

### 4.2 시나리오별 사용자 여정

#### 시나리오 1: 첫 방문 사용자

1. 사용자가 서비스에 접속
2. 메인 리스트에서 포켓몬 목록 확인
3. 관심있는 포켓몬 카드 클릭
4. 상세 페이지에서 정보 확인
5. 자동으로 "최근 본 포켓몬"에 저장됨
6. 뒤로가기 버튼으로 목록으로 복귀

#### 시나리오 2: 재방문 사용자

1. 사용자가 서비스에 재접속
2. 헤더의 "최근 본 포켓몬"에서 이전에 본 포켓몬 확인
3. 회전하는 포켓몬 이름 클릭
4. 바로 해당 포켓몬 상세 페이지로 이동

### 6.1 기술 스택

| 분류            | 기술         | 설명                         |
