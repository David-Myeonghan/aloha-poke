# IndexedDB 정리

## 개요

브라우저에서 대용량 데이터를 저장할 수 있는 클라이언트 사이드 NoSQL 데이터베이스.

## 주요 개념

### 객체 저장소 (Object Store)

- IndexedDB에서 데이터를 저장하는 기본 단위 (SQL 테이블과 유사)
- JavaScript 객체를 key-value 쌍으로 저장
- 생성 시 고유 키 경로(key path) 지정 가능

### Index

- 객체 저장소에 저장된 데이터를 빠르게 검색할 수 있도록 도와줌
- 특정 속성을 기준으로 생성, 검색 최적화에 사용
- DB 에서 그 인덱스.

## 이벤트 발생 순서

1. `onupgradeneeded` - 데이터베이스 생성 또는 버전 업그레이드 시
2. `onsuccess` - 데이터베이스 연결 성공 시
3. `onerror` - 데이터베이스 연결 실패 또는 오류 발생 시
4. `oncomplete` - 트랜잭션 완료 시
